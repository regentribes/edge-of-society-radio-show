# Edge of Society — Website Documentation

## Overview

The **Edge of Society** website is a public-facing landing page for the show — a talk show exploring regenerative communities, their guests, episode topics, and listen links. It is deployed at the root of the repository on **GitHub Pages**.

**Live URL:** https://regentribes.github.io/edge-of-society-radio-show/

**Repository:** https://github.com/regentribes/edge-of-society-radio-show

---

## Project Structure

```
edge-of-society-radio-show/
├── index.html          # Main website (single page)
├── cover.jpg           # Main show cover art
├── covers/             # Episode cover images (ep01.png – ep10.png)
├── README.md          # Show concept & guest list

│   └── EDITING.md      # How to edit and update content
└── .github/
    └── workflows/
        └── pages.yml   # GitHub Pages CI/CD pipeline
```
